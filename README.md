# 3D Menu Project

An interactive 3D menu webpage built with modern CSS transforms and JavaScript interactivity.

## Features

✨ **3D Effects:**
- Perspective transforms with rotateX and rotateY
- Depth effect with translateZ
- Dynamic hover states
- Smooth transitions

🎨 **Interactive Elements:**
- Menu items respond to mouse movement
- Icons rotate on hover
- Text glow effects
- Smooth content transitions

⌨️ **Navigation:**
- Click menu items to view sections
- Keyboard arrow key navigation
- Smooth scrolling

📱 **Responsive:**
- Works on desktop, tablet, and mobile
- Reduced 3D effects on smaller screens
- Touch-friendly interface

## Files

- `index.html` - HTML structure
- `styles.css` - CSS styling with 3D effects
- `script.js` - JavaScript interactivity
- `README.md` - Project documentation

## How to Use

1. Clone the repository
2. Open `index.html` in your web browser
3. Hover over menu items to see the 3D effects
4. Click menu items to navigate between sections
5. Use arrow keys for keyboard navigation
